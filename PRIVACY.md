# Privacy Policy

CPEFinder is designed to operate locally.

- The application does not include telemetry, analytics, advertising, account tracking, or cloud synchronization.
- The application does not transfer user information to external networked systems.
- Network traffic initiated by the application is limited to functionality explicitly requested by the user, such as local device discovery and opening the selected device address.
- Discovered device information is kept in application memory unless the user explicitly copies or exports it.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.
