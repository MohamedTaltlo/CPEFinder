# Contributing

Contributions are welcome under the MIT License.

1. Fork the repository.
2. Create a focused branch.
3. Keep changes small and reviewable.
4. Build the Windows target before submitting a pull request.
5. Do not add proprietary dependencies, telemetry, bundled adware, credential collection, exploit code, or binaries that cannot be reproduced from public source.

Changes to build/release/signing workflows require the same review as application source code.
