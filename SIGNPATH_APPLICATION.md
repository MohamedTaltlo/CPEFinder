## Suggested project description

CPEFinder is an open-source Windows utility for discovering and identifying CPE/network devices on a local network. It displays device-advertised management information such as IPv4 address, MAC address, model, device name, SSID and firmware version when available. It does not exploit vulnerabilities, bypass authentication or scan for exploitable security weaknesses.

## Before applying

- Enable MFA on GitHub and SignPath accounts.
- Publish the repository publicly.
- Create at least one release using a `vX.Y.Z` tag.
- Keep the release binary generated by GitHub Actions, not by a local unpublished build.
- Confirm all source/build scripts are under the OSI-approved MIT license and no proprietary components are bundled.
